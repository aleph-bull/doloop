# Brand sources

Working files for the Komodon logo (the komo21 face) and earlier names (Doloop, Pomodo),
copied here from the project folder so they are backed up with the code. `.pdn` files open
in Paint.NET. The mark the app draws comes from `komo3.0.png` and, at 32px and under, `komo3.0small.png`
(`packages/ui/scripts/prepare-icons.ts`, `packages/ui/src/logo.ts`).
